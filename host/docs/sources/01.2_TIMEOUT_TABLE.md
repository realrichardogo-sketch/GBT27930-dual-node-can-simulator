## Identifiers: Standard vs Project

- **The standard defines no timer identifiers.** Timeouts appear as
  flowchart annotations ("超时: 自首次发送CHM报文起10 s") and in the
  Chapter 11 message-function text.
- The IDs `TO-01` … below are **document-local labels** for this draft.
- The project's earlier wait labels (W2, W6a, W6, W7, W7b, W8, W9, W10,
  W15, W16, W17 and the T rows in `PROJECT_1_SPEC_v2.0.txt`) are
  **project-specific**. Their original definitions were not recovered,
  so **no mapping is made** here (column "Project alias" = not mapped).
  Mapping them requires the original table or an owner decision.

transmission of message X. "→ A.2 / A.3" = enter the reception-timeout

messages, send CEM / BEM, then exit or reconnect (see 01.2_STATE_MACHINES.md).
