## 3. Parameter (SPN) Definitions (Tables 8–29)

Column conventions: **Start** is the standard's "起始字节或位" (byte
number, or byte.bit for bit fields). **Opt.** is the standard's 发送选项:
M = 必须项 (mandatory), O = 可选项 (optional). Resolution, offset, range
and unit are given only where the standard prints them; "—" means the
standard prints none. Bit fields use the standard's codes; for two-bit
status codes the standard defines 00/01/10 and does not define 11.

### 3.23 Charging-phase application rules (§11.3.1, p.14 / pdf 18)

- CV mode: output voltage meets the voltage demand; output current does
  not exceed the current demand. CC mode: output current meets the
  current demand; output voltage does not exceed the voltage demand.
- In CC mode, the BCL voltage demand shall not exceed the CML maximum
  voltage; otherwise the charger uses its own maximum voltage as the
  voltage limit.
- Current demand > CML maximum current → output at maximum capability;
  within range → output the requested current; below the charger's
  minimum current → output at minimum capability.
- Voltage demand < the charger's minimum voltage → the charger shall send
  CST to stop.
- The current demand shall be the vehicle's actual need and not be
  influenced by changes in the charger's output capability.

### 3.24 Charging-current sign semantics

What the standard states (no interpretation added):

- §5.4 (p.5 / pdf 9): charging current values are negative; a received
  charging current outside −400 A ~ 0 A ends the charging process at
  public sites.
- All charging-current SPNs use 0.1 A/bit with a −400 A offset: SPN2817
  (BCP), SPN2826 and SPN2827 (CML), SPN3073 (BCL), SPN3076 (BCS),
  SPN3082 (CCS). The signed physical value on CAN is therefore
  0.1 × raw − 400 A.
- §11.3.1 (p.14 / pdf 18) compares currents in words only: demand
  "大于" (greater than) the CML maximum current, demand "小于" (less
  than) the charger's minimum current, "最大/最小" (maximum/minimum)
  output capability.
- Further current comparisons stated in words only: §11.3.1 CV mode,
  output current "不应超过" (shall not exceed) the current demand;
  SPN3513 bits 1–2 (BST), "电流超过需求值" (current exceeds demand)
  (p.19 / pdf 23).

Three distinct representations must be kept apart:

| Representation | Source | Status |
|---|---|---|
| Signed current on CAN (negative = charging) | §5.4, SPN definitions | Standard |
| Current magnitude used by application-level control | Not defined by the standard | Project decision required |
| Sign convention at the interface to the Project 2 power converter | Not defined by the standard | Project decision required |

Whether the §11.3.1 comparisons apply to signed physical values (where
"greater" and "maximum" invert for negative numbers) or to magnitudes is
**not stated** by the standard. No comparison rule and no conversion
policy is defined in this document; see OQ-12.

*Status note (B3-B, 2026-11-09):* the representations have since been
decided (D-02: CAN signed; application and Project 2 non-negative mA)
and the §11.3.1 comparison domain is magnitude-based (D-06); see
`docs/REQUIREMENTS_BASELINE.md` COM-6 and PROT-7. The zero-current
interpretation remains OPEN (baseline §6.5, OQ-12(a) / zero-current).
